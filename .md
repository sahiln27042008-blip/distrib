## 6. Fault search engine (physics/search/)

```
enumerateFaults(graph) → ConsonantFault[]
  │
  ├── explicit candidates (from graph.candidatePerturbations)
  │   priority 0 (tried first)
  │
  └── default candidates (per vowel kind, priority 1):
        CHANNEL → DELAY(1ms), SEVER(PRE_COMMIT), SEVER(POST_COMMIT),
                  DUPLICATE(2), CORRUPT(SCHEMA_DRIFT)
        LEASE   → SATURATE(loadUnits = maxCapacity)
        LOG     → DELAY(1ms), CORRUPT(LOSSY_DROP)
        CELL    → WIPE(VOLATILE_CELLS) [if persistence = VOLATILE]

searchFaults(graph, {maxDepth=3, maxEvaluations=5000}, seed):
  │
  1. baseline = executeFaultSequence(graph, [], seed)
     if baseline.violatedInvariants → BASELINE_FAILURE
  │
  2. for depth = 1..maxDepth:
  │      BFS over candidate sequences of length `depth`
  │      dedup via JSON.stringify(sequence)
  │      budget-capped at maxEvaluations
  │      if any sequence violates → FAILURE_FOUND + minimal counterexample
  │
  3. else → NO_FAILURE_WITHIN_BOUND
  │
  returns: { status, minimalCounterexample?, violatedInvariants,
             depthReached, evaluations, durationMs,
             deterministicFingerprint }  ← SHA-256 of graph+seed+resultBase
                                              (durationMs EXCLUDED from hash)

cliff-finder.ts:
  findCollapseCliff(graph, channelId, minMs, maxMs, tolerance=50)
  → binary search for exact ms where invariant breaks
```

## 7. The scientist → gate pipeline

```mermaid
sequenceDiagram
  participant Gate as run_gate
  participant Sci as runScientist
  participant Hyp as generateHypotheses
  participant Exp as runExperiment
  participant Min as minimizeCounterexample
  participant Prop as proposeFixTool
  participant Ver as verifyFixTool

  Gate->>Sci: runScientist(config, maxExperiments=10)
  
  loop until maxExperiments or no hypotheses
    Sci->>Hyp: generate hypotheses (LLM)
    Hyp-->>Sci: FailureHypothesis[]
    
    alt hypothesis is duplicate
      Sci-->>Gate: stop (inconclusive: repeated experiment)
    else
      Sci->>Exp: runExperiment(hypothesis, baseConfig)
      Exp->>Exp: interventionsToConfig(baseConfig, interventions)
      Exp->>Exp: MatrixScenario.run() → trace
      Exp->>Exp: audit_trace → Findings[]
      Exp-->>Sci: ExperimentResult {provenFindings, trace, ...}
      
      alt proven findings found
        Sci->>Min: minimizeCounterexample(failure)
        Min-->>Sci: minimal events
        Sci->>Sci: record DiscoveredFailure
      end
    end
  end
  
  alt no hypotheses generated
    Gate->>Gate: baseline audit per invariant
    loop for each invariant (r04, r05, r10)
      Gate->>Exp: runExperiment(empty interventions)
      alt violations found
        Gate->>Gate: record baseline failure
      end
    end
  end
  
  Gate->>Min: minimize each failure
  Gate->>Prop: proposeFixTool.handler(finding, config)
  Prop-->>Gate: CodePatch {diff, dialEquivalent}
  Gate->>Ver: verifyFixTool.handler(original, fixed, ruleId)
  Ver-->>Gate: PatchVerificationResult
  
  Gate-->>Gate: APPROVED if no failures OR all patches verified
  Gate-->>Gate: BLOCKED if failures remain
```

│                                                      │

│  SimEvent:                                            │

│    t: number            ← virtual ms                  │

│                                                      │
│  Rng:                                                 │
│    next() → [0,1)     ← mulberry32 PRNG              │
│    int(lo, hi)        ← integer in range              │

│  LimitError thrown when:                              │
│    log.length >= maxEvents                           │

           No Date.now() in simulation path.

## 14. Agent loop flow (detailed)

```mermaid
sequenceDiagram
  participant C as Client
  participant S as mcp/server.ts
  participant L as agent-loop.ts
  participant O as Orchestrator
  participant T as McpTool

  C->>S: POST /agent_message {text, sessionId, image?}
  S->>S: getSessionFromReq (30-min TTL check)
  S->>L: runAgentLoop({history, userText, tools, orchestrator, context})
  
  L->>L: Inject SYSTEM_PROMPT if missing
  L->>L: Inject [Active Workflows] summary if workflows exist
  L->>L: Inject user image if vision model
  
  loop MAX_ITERATIONS (6, capped by env)
    L->>L: if messages.length > 30 → compact:
    L->>L:   keep [system, activeWfs?, firstUserMsg, syntheticNote, ...last20]
    L->>L:   remove orphaned tool messages (no matching assistant tool_call_id)
    
    L->>L: isFinalIteration = (i == MAX_ITERATIONS - 1)
    L->>L: currentTools = isFinalIteration ? [] : toolDefs
    
    L->>O: orchestrator.chat(messages, currentTools)
    O-->>L: {text, tool_calls, stop_reason}
    
    L->>L: resolve tool names (exact → prefix-match → pass-through)
    
    alt no tool_calls
      alt text matches "Tool: xxx" pattern
        L-->>S: error: model wrote tool name as text
      else
        L-->>S: buildGraphDataResult(text, stop_reason)
      end
    else tool_calls present
      loop for each tool call
        L->>L: check same-tool-same-args (3x = stop)
        L->>L: check circuit breaker (3 errors = stop)
        L->>T: tool.handler(args, context)
        T-->>L: result
        
        alt create_workflow succeeded
          L->>L: activeWorkflowId = result.workflowId
          L->>L: associateWorkflowWithSession()
        else audit_trace succeeded
          L->>L: context.lastFindings = findings
          L->>L: context.lastFinding = first proven finding
        else run_matrix succeeded
          L->>L: context.lastTrace = result.trace
          L->>L: compact trace in message (stub note)
        end
        
        L->>L: push tool result to messages
      end
      
      alt circuit broken
        L-->>S: error: 3 consecutive tool errors
      end
    end
  end
  
  alt loop exhausted with tool calls
    L->>O: final synthesis chat (tools=[])
    O-->>L: finalResp.text
    L-->>S: buildGraphDataResult(finalText, "stop")
  end
  
  S-->>C: SSE stream OR JSON-RPC {reply, stopReason, toolCalls, graphData}
```
